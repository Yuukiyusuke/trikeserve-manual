# TrikeServe User Manual

Standalone static manual site (English and Filipino) with downloadable PDF guides.

## Deploy to Vercel

1. Import this repository in Vercel as a new project (separate from the TrikeServe app project).
2. Select the **Other** framework preset, leave the build and install commands blank, and set the output directory to **.** (the project root).
3. Deploy. The English guide is at / and the Filipino guide is at /fil/.

No app source, environment files, dependencies, or build step are needed.
